# Horizon Zero-G – Updates

Öffentliche Ablage für das Update im Spiel. Das Spiel liest `update.json` und lädt die Patch-Pakete aus `files/`
(nur geänderte Dateien gegenüber der installierten Grundversion, in Stücken zu 95 MB, mit SHA-256 geprüft).
Erzeugt mit `tools/make_update.sh` im Spiel-Repository. Bitte nichts von Hand ändern.
